## 1. 产品概述
创新文字麻将牌面设计展示页——将178张文字麻将牌（162张基础字牌 + 16张功能牌）以极具东方美学的交互式网页呈现。每张牌面不仅是文字载体，更是一件融合书法韵味与现代设计的微型艺术品。
- 目标：为文字麻将游戏打造一套视觉震撼、交互丰富的牌面展示系统，让玩家在浏览中感受汉字之美与游戏创意
- 价值：既是游戏道具展示，也是汉字文化的数字艺术呈现

## 2. 核心功能

### 2.1 功能模块
1. **牌面总览页**：以九大类别分区展示全部178张牌，支持分类筛选与交互预览
2. **单牌详情弹窗**：点击任意牌面展开大图，展示牌面设计细节、所属类别、功能说明
3. **规则说明书**：完整展示游戏规则，包含核心玩法、胡牌条件、功能牌详解

### 2.2 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 牌面总览页 | 英雄区域 | 标题动画、墨韵背景、核心数据（178张牌/9大类别） |
| 牌面总览页 | 类别导航 | 九大类别标签栏，支持点击筛选与全部展示 |
| 牌面总览页 | 牌面网格 | 每类18张牌以网格排列，悬停翻转/发光效果 |
| 牌面总览页 | 功能牌专区 | 8种功能牌特殊展示，含功能说明 |
| 牌面总览页 | 规则说明 | 可展开/收起的完整规则说明书 |
| 牌面详情弹窗 | 牌面大图 | 高清牌面展示、类别标签、功能描述 |

## 3. 核心流程
用户进入页面 → 浏览英雄区域 → 滚动查看各类别牌面 → 点击类别标签筛选 → 点击单牌查看详情 → 展开规则说明了解玩法

## 4. 用户界面设计

### 4.1 设计风格
- **风格定位**：墨韵东方——传统水墨美学 × 现代数字交互
- **主色调**：墨黑(#1a1a2e) + 宣纸白(#f5f0e8) + 朱砂红(#c23616)
- **辅助色**：九大类别各有专属色系（人物-琥珀、自然-翠绿、动作-赤红、形容-靛蓝、时空-紫灰、数字-金棕、抽象-青碧、语法-灰墨、颜色-五彩渐变）
- **牌面风格**：仿象牙白牌面 + 圆角 + 浮雕阴影 + 类别角标色带
- **字体**：标题使用书法风格字体，牌面文字使用宋体/楷体
- **布局**：纵向滚动、卡片网格、沉浸式全屏英雄区

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 牌面总览页 | 英雄区域 | 全屏墨韵渐变背景、毛笔字标题动画、飘散墨点粒子、核心数据统计 |
| 牌面总览页 | 类别导航 | 横向滚动标签栏、类别色带标识、选中态下划线动画 |
| 牌面总览页 | 牌面网格 | 3D透视卡片、悬停翻转/浮起效果、类别色带角标、牌面大字居中 |
| 牌面总览页 | 功能牌专区 | 深色背景区隔、功能图标+文字说明、特殊边框发光 |
| 牌面总览页 | 规则说明 | 手风琴展开、章节图标、表格排版功能牌 |

### 4.3 响应式设计
- 桌面优先（1920×1080基准）
- 平板适配：牌面网格从6列调整为4列
- 移动端适配：牌面网格调整为3列，导航改为下拉选择

### 4.4 牌面视觉设计细节
- **基础字牌**：象牙白底(#faf6ee)、圆角12px、右上角类别色带、中心大字（楷体/宋体）、底部小字类别名、微浮雕阴影
- **功能牌**：深墨底(#1a1a2e)、金色边框、【】括号装饰、功能图标、朱砂红功能名
- **交互效果**：悬停时牌面微微浮起+阴影加深、点击时翻转动画、选中时发光边框
